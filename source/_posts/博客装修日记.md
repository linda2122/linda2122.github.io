## 1.换主题Fluid
- **第一步：安装 Fluid**
>在 VS Code 中打开你的博客项目，打开终端，确认当前目录正确，当前目录为myblog下。
    - 备份当前配置： `Copy-Item _config.yml _config.yml.backup`
    - 安装 Fluid: `npm install --save hexo-theme-fluid`
- **第二步：启用 Fluid 主题**
>打开博客根目录的 _config.yml，找到：
    `theme: landscape`
    改为：
    `theme: fluid`
    检查language，若language为`en`，改为  `language: zh-CN`

- **第三步：创建 Fluid 的主题配置文件**
>Fluid 官方建议在博客根目录创建 _config.fluid.yml(与_config.yml同级)
    先找到安装后的默认主题配置文件：`node_modules/hexo-theme-fluid/_config.yml`,
    把它的内容复制到博客根目录新建的 _config.fluid.yml 中。
- **第四步：本地预览**
    ```
    npx hexo clean
    npx hexo generate
    npx hexo server
    ```

## 2.换字体和段落
- **第一步：修改字体设置**
在 `_config.fluid.yml`中找到font:  
```
font:
  font_size: 16px
  font_family:
  letter_spacing: 0.02em
  code_font_size: 85%
```
改成
```
font:
  font_size: 16px
  font_family: '"PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif'
  letter_spacing: 0.02em
  code_font_size: 85%
```
- **第二步：添加段落间距和行距**
找到custom_css:，目前是空的。
在myblog目录source文件夹下创建文件夹css，在css下创建文件custom.css  
在 custom.css 中粘贴下面的内容：  
```

/* 全局正文排版 */
body {
  line-height: 1.9;
}

/* 文章正文 */
.post-content {
  font-size: 16px;
  line-height: 1.9;
  letter-spacing: 0.02em;
}

/* 文章段落间距 */
.post-content p {
  margin-bottom: 1.2em;
}

/* 文章标题 */
.post-content h1,
.post-content h2,
.post-content h3,
.post-content h4 {
  line-height: 1.5;
  margin-top: 1.8em;
  margin-bottom: 0.8em;
}

/* 列表排版 */
.post-content li {
  line-height: 1.85;
  margin-bottom: 0.35em;
}

/* 手机端 */
@media (max-width: 768px) {
  .post-content {
    font-size: 15px;
    line-height: 1.85;
  }
}
```

- **第三步：让 Fluid 加载这个 CSS**
回到 _config.fluid.yml，找到`custom_css:`：  
修改为：  
`custom_css:  ./source/css/custom.css`
注意缩进：- /css/custom.css 前面要有两个空格。

- **第四步：让 Fluid 加载这个 CSS**
保存所有文件后，在 VS Code 终端运行：
```
npx hexo clean
npx hexo server
```

## 3.新增关于页
1、首次使用主题的「关于页」需要手动创建：
`hexo new page about`  
创建成功后，编辑博客目录下 /source/about/index.md，添加 layout 属性。  
修改后的文件示例如下：  
```
  ---
  title: about
  layout: about
  ---

  这里写关于页的正文，支持 Markdown, HTML
```

## 4.使用一个导航页 + 多篇独立文章
导航页负责说明学习路线、维护章节顺序；每章作为一篇 Hexo 文章，方便单独写作、预览、归档和交叉链接。  
导航页可以用 Hexo 命令创建：  
```
npx hexo new page "深度学习" --path learning/deep-learning/index.md
```
里面维护系列介绍和章节目录：
```text
---
title: 深度学习学习笔记
---

记录我学习深度学习的过程、概念和实践。

## 章节目录

1. {% post_link dl-01-linear-algebra 线性代数基础 %}
2. {% post_link dl-02-probability 概率与统计基础 %}
3. {% post_link dl-03-neural-network 神经网络基础 %}
4. {% post_link dl-04-backpropagation 反向传播 %}
```

每章仍是独立文章，例如 source/_posts/dl-01-linear-algebra.md：
```text
---
title: 线性代数基础
date: 2026-10-14 10:00:00
categories:
  - 深度学习
tags:
  - 学习笔记
---
```

## 文章置顶
当前使用 Fluid，且已启用置顶图标；但项目还没有置顶排序插件，所以仅加标记不会把文章排到首页前面。
在项目根目录安装插件：
```Powershell
npm install hexo-generator-index-pin-top --save
```

然后在要置顶文章的 front matter 中加 sticky 数值：  
```text
---
title: 深度学习学习笔记
date: 2026-10-14
sticky: 10
---
```
数字越大，置顶优先级越高。取消置顶时删除 sticky 字段。你现有的 Fluid 配置会显示置顶图标，首页列表排序配置 当前按日期排序；
