## 博客创建过程
目标：
- 只想让个人博客能够被别人访问
- 方案：GitHub Pages：Hexo 在自己的电脑上生成静态网页，然后通过 GitHub Pages 发布。网站会有类似 https://你的用户名.github.io 的地址。GitHub 官方支持这种静态网站托管。
- 优点：配置简单、无需维护服务器、适合长期写博客。
### 第一步：安装本地开发环境
Windows:
安装Node.js、Git，
验证
```
    node -v
    npm -v
    git --version
```
### 第二步：创建 Hexo 博客项目
新建文件夹：myblog
终端进入该文件夹
1. 安装 Hexo 命令行工具
`npm install -g hexo-cli`
检查是否安装成功：
`hexo -v`
2. 初始化博客
```
hexo init .
npm install
```
然后在 VS Code 中打开myblog文件夹.
3. 启动本地预览
`npx hexo server`

终端通常会显示本地访问地址，例如：http://localhost:4000/ 按住 Ctrl 点击地址，或者复制到浏览器打开，就可以看到 Hexo 默认博客。
按 Ctrl + C 可以停止本地服务。
4. 认识一下目录结构
```
myblog/
    source/_posts/
    存放你的 Markdown 博客文章。以后主要编辑这里。
    _config.yml
    博客标题、网址、主题等全局配置。
    themes/
    博客主题的文件目录。
    public/
    Hexo 生成的静态网页，一般不需要手动编辑。
    package.json
    记录项目依赖及 npm 脚本。
```
### 第三步：在 GitHub 创建博客仓库
打开并登录github账号，新建仓库，在Repository name 中填写：`你的GitHub用户名.github.io`
选择 Public,不要勾选添加 README、.gitignore 或 License，先创建一个空仓库。
GitHub Pages 的官方说明可以参考：GitHub Pages 文档;
创建后，仓库地址类似： https://github.com/alice123/alice123.github.io

### 第四步：将本地 Hexo 项目推送到 GitHub
回到 VS Code 的终端，确认当前目录仍然是 myblog。
1. 配置 Git 身份
git config --global user.name "你的名字"
git config --global user.email "你的GitHub邮箱"
2. 初始化仓库并上传源码
```
git init
git add .
git commit -m "Initial Hexo blog"
git branch -M main
git remote add origin https://github.com/你的用户名/你的用户名.github.io.git
git push -u origin main
```
如果 GitHub 要求登录，按照系统弹出的浏览器授权提示完成认证即可。不要把 GitHub 密码或个人访问令牌直接写进命令或配置文件。
上传成功后，刷新 GitHub 仓库页面，就能看到 Hexo 的源码文件了。

### 第五步：配置 GitHub Actions 自动部署
1. 修改 Hexo 的网站地址
在 VS Code 中打开根目录下的 _config.yml，找到 url 和 root 两项，修改为：
```
url: https://你的用户名.github.io
root: /
```
我没找到root，root就没加。
2. 创建部署配置文件
在 VS Code 中可以直接新建文件夹 .github（有的话无需新建），在里面新建 workflows 文件夹，再新建 deploy.yml。
```

name: Deploy Hexo to GitHub Pages

on:
  push:
    branches:
      - main
  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: github-pages
  cancel-in-progress: true

jobs:
  build-and-deploy:
    runs-on: ubuntu-latest

    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}

    steps:
      - name: Checkout repository
        uses: actions/checkout@v4

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: '22'
          cache: npm

      - name: Install dependencies
        run: npm ci

      - name: Generate Hexo site
        run: npx hexo generate

      - name: Setup GitHub Pages
        uses: actions/configure-pages@v5

      - name: Upload generated site
        uses: actions/upload-pages-artifact@v4
        with:
          path: ./public

      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4

```
将上面内容完整复制进去。
上述配置会在 main 分支收到推送时执行以下工作：
- 下载仓库里的 Hexo 源码。
- 安装 Node.js 22 和项目依赖。
- 运行 npx hexo generate，生成 public 目录。
- 将 public 中的网页发布到 GitHub Pages。
这符合 GitHub Pages 官方推荐的自定义 Actions 部署流程[https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages]。

3. 再次提交并推送
```
git add .
git commit -m "Configure GitHub Pages deployment"
git push
```
此时 GitHub 就会自动开始部署。

4. 在 GitHub 开启 Pages
打开你的仓库，依次进入：
    1. Settings
    2. 左侧的 Pages
    3. 在 Build and deployment 下找到 Source
    4. 选择 GitHub Actions
保存后即可。这个设置告诉 GitHub 使用 Actions 发布网站，而不是直接从源码分支发布。

5. 查看部署状态
点击仓库顶部的 Actions 标签页，打开名为 Deploy Hexo to GitHub Pages 的工作流。
绿色勾号：部署成功。
黄色图标：正在执行。
第一次部署可能需要几分钟。成功后，在仓库 Settings → Pages 页面查看网站地址，或者直接打开：`https://你的用户名.github.io/`

### 第六步：以后如何写博客和更新网站？[hexo发布博客操作手册]
#### 创建一篇新文章
在 VS Code 终端执行：`npx hexo new "我的第一篇博客" `

Hexo 会在 source/_posts/ 下生成一个 Markdown 文件。

打开文件，写入例如：
```
---
title: 我的第一篇博客
date: 2026-10-13 10:00:00
tags:
- 随笔
categories:
- 博客创建
---

# 欢迎来到我的博客

这是我使用 Hexo、VS Code 和 GitHub Pages
搭建的个人博客。

以后我会在这里记录学习笔记和生活感悟。

```

#### 本地预览效果
`npx hexo server`
浏览器打开 http://localhost:4000/，检查文章和页面是否正常。

#### 发布到线上
确认没有问题后，在终端执行：
```
git add .
git commit -m "Add my first post"
git push
```
或者vscode内手动commit。
注意：每次只要源码提交并推送成功，就会自动触发工作流，不需要手动上传 public 目录。
